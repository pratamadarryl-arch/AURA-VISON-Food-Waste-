# Persyaratan Sistem & Perangkat (System Requirements) — AURA-VISION

Dokumen ini berisi daftar kebutuhan perangkat keras dan perangkat lunak yang diperlukan untuk menjalankan prototipe website AURA-VISION.

---

## 1. Kebutuhan Perangkat Keras (Hardware Requirements)

| Komponen | Spesifikasi Minimum | Spesifikasi Direkomendasikan |
|---|---|---|
| **Perangkat** | Komputer Desktop / Laptop / Tablet | Laptop / Komputer Desktop Modern |
| **Sistem Operasi** | Windows 10/11, macOS 11+, atau Linux | Windows 11 atau macOS Terbaru |
| **Memori (RAM)** | Minimum 4 GB RAM | 8 GB RAM atau lebih |
| **Kamera (Webcam)** | Kamera Bawaan Laptop / USB Webcam *(Opsional)* | Webcam HD (720p/1080p) untuk simulasi pemindaian |
| **Layar / Resolusi** | Minimal 360 x 800 px (Mendukung Ponsel) | 1366 x 768 px atau 1920 x 1080 px |

---

## 2. Kebutuhan Perangkat Lunak (Software Requirements)

1. **Node.js**: Versi **18.0.0** atau lebih baru (Disarankan versi LTS / Long Term Support).
   - Tautan Unduh Resmi: [https://nodejs.org/](https://nodejs.org/)
2. **NPM (Node Package Manager)**: Versi 9.0.0 atau lebih baru (Otomatis terpasang saat menginstal Node.js).
3. **Web Browser Modern**:
   - Google Chrome (Direkomendasikan)
   - Microsoft Edge
   - Mozilla Firefox
   - Apple Safari

---

## 3. Kebutuhan Koneksi Internet

- **Saat Instalasi Pertama**: Diperlukan koneksi internet aktif untuk mengunduh pustaka (*dependencies*) aplikasi.
- **Saat Menjalankan Aplikasi**: Dapat dijalankan secara offline di komputer lokal (*localhost*).
